# Go Interview — PWA для подготовки к собесу

Офлайн-приложение: банк вопросов (Go senior/staff), конспекты, конспект по System Design
и тренажёр-карточки. Ставится на телефон как обычное приложение и работает без интернета.

Разделы:

- `go-interview-bank.html` — банк вопросов по грейдам с режимом карточек и прогрессом.
- `go-interview-konspekty.html` — теория «с нуля»: алгоритмы, память, конкурентность, сети, БД.
- `go-interview-system-design.html` — System Design: методика интервью, все разделы теории
  со схемами и разборы систем с логом диалога интервьюер ↔ кандидат.
- `go-interview-tasks.html` — лайвкодинг и «что выведет» с эталонными решениями.
- `go-interview-mocks.html` — сценарии мок-собеседований.
